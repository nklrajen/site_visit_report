# Axiom Technical Services — Site Visit Report App

A Flutter Android app for field executives to fill out site visit reports offline.

## Quick Start
1. Install Flutter SDK (https://flutter.dev)
2. Run `flutter pub get`
3. Run `flutter build apk --release`
4. Find APK at `build/app/outputs/flutter-apk/app-release.apk`

See BUILD_INSTRUCTIONS.md for full details.

## Features
- 10-section form matching the paper form
- SQLite local storage, fully offline
- Auto-save every 30 seconds
- GPS capture + Google Maps integration
- Camera photos attachment
- Digital signature capture
- Search, edit, delete reports
- Export as JSON or CSV
- Inspector profile in Settings
